## 申し込みに直結（最優先）
| 箇所 | 確認すること |
|---|---|
| 料金・入会 | 月会費／入会金／オンライン面談は無料か |
| 料金・入会 | 申し込みフォームのURL（`assets/js/main.js` の `FORM_URL` に入れる） |
| 料金・入会 | 募集の期（第◯期）・募集期間・定員 |
| 入会フロー | 面談の所要時間／審査の有無／支払方法 |
| 会費に含まれるもの | 懇親会費の扱い、1on1の初回の扱い・2回目以降の金額 |

## FAQ・問い合わせ
- 定例会を欠席した場合のフォロー（録画・資料共有など）
- 学生の参加条件・料金／対象職種の範囲（柔道整復師・鍼灸師など）
- 遠方在住者の参加（オンライン参加の可否）
- 退会方法・最低在籍期間
- 問い合わせ先（フォーム／メール／SNSのDM）

## メンバーの声の扱い（決めたルール）
- 氏名は載せていない。引用には「職種・経験年数」のみ添えている（アンケートの掲載同意の範囲内）
- 匿名希望の方の具体的な実績（例：500人集客）は、職種・年数も外して載せている（人数が少なく特定されやすいため）
- 引用は読みやすさのため表現を整えている → 掲載前に本人確認を取る（アンケート運用メモの方針どおり）
